`frontend/lib/priceStore.ts` — implement a tiny pub/sub store (no Zustand dependency needed for Phase 1):

- Exports `type PriceUpdate = { ticker: string; price: number; previous_price: number; timestamp: string; change: number; change_percent: number; direction: 'up' | 'down' | 'flat' }`. Matches `PriceUpdate.to_dict()` from `backend/app/market/models.py` — verify field names against that source while implementing.
- Module-scope `prices: Map<string, PriceUpdate>` and `subscribers: Map<string, Set<(p: PriceUpdate) => void>>`.
- `setPrice(update: PriceUpdate): void` — writes to map; invokes per-ticker subscribers.
- `getPrice(ticker: string): PriceUpdate | undefined`.
- `subscribe(ticker: string, fn: (p: PriceUpdate) => void): () => void` — returns unsubscribe.
- Export `__resetForTests(): void` (private — only imported by tests) that clears both maps.

`frontend/lib/useEventStream.ts` — React hook that opens an `EventSource` on mount and feeds the store:

- `'use client'` directive at the top.
- `export function useEventStream(url: string = '/api/stream/prices'): { connected: boolean }`.
- On mount: `const es = new EventSource(url)`; `es.onmessage = (e) => { const data: PriceUpdate = JSON.parse(e.data); setPrice(data); }`. Wrap the `JSON.parse` in a try/catch and `console.warn` on parse failure (don't throw — the SSE channel may send keep-alive comments).
- `es.onopen = () => setConnected(true)`; `es.onerror = () => setConnected(false)`.
- Cleanup on unmount: `es.close()`.
- Return `{ connected }`.
